# MetatraderSharp-LivePrices-Demo

A demo WinForms app showing how the MetatraderSharp API can be used to stream live prices from a MetaTrader terminal. 

![image](https://github.com/user-attachments/assets/d645e534-751f-4477-af5d-3d77754f35bc)

## Usage Requirements
Successful usage of the MetatraderSharp-LivePrices demo requires:
- a copy of MetaTrader 4/MetaTrader 5 to be installed 
- MTsocketAPI should be installed and then loaded onto a chart in the terminal with the default port settings unchanged

For more information on how to install the MTsocketAPI please consult: https://www.mtsocketapi.com/

## Disclaimer
This is a sample application created to demonstrate price tracking functionality and is provided as is. It is not intended to be used as a support for live trading.
